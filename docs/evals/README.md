# Поведенческая проверка навыков

skills.jsonl содержит 14 задач и наблюдаемые критерии. Это набор для будущих прогонов модели, а не результат тестирования её поведения.

Для сравнения выберите один prompt и снимок тестовой базы/репозитория. Зафиксируйте модель, effort, начальный контекст и доступные инструменты. В варианте B меняйте только одну инструкцию. Запускайте варианты из одной базы независимо; не используйте production. Сохраните реальную трассу вызовов и созданные артефакты, verdict по каждому критерию, usage модели, время и стоимость из фактического биллинга. Повторите несколько раз: один удачный ответ не доказывает устойчивость.

Контрактные pytest проверяют сервер и упаковку детерминированно. check_skills проверяет метаданные и ссылки. Они не измеряют выбор навыка моделью, качество ответа, токены или стоимость. Уменьшение числа слов в инструкции тоже не равно измеренной экономии токенов.
