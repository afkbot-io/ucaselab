# Проверка поведения агента с навыками

В [skills.jsonl](skills.jsonl) собраны 17 задач с наблюдаемыми критериями оценки. Они предназначены для будущих прогонов модели. Наличие задачи и критериев не означает, что проверка выполнена или пройдена.

## Как сравнивать инструкции

Выберите одну задачу и закрепите снимок тестовой базы или репозитория. Используйте только изолированные тестовые данные, без подключения к рабочим системам. Зафиксируйте модель, уровень рассуждений (`effort`), начальный контекст и доступные инструменты.

Запускайте оба варианта независимо из одного исходного состояния. Во втором варианте меняйте только одну инструкцию. Сохраняйте фактическую трассу вызовов, созданные артефакты и результат по каждому критерию. Расход токенов берите из данных использования модели, время измеряйте, стоимость указывайте по фактическому биллингу. Повторите сравнение несколько раз: один удачный ответ не показывает устойчивость поведения.

## Что проверяют автотесты

Контрактные pytest проверяют сервер и упаковку, а `check_skills.py` — метаданные и ссылки. Эти проверки не измеряют выбор навыка моделью, качество ответа, расход токенов или стоимость. Более короткая инструкция сама по себе не доказывает экономию токенов.
