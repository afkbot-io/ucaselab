# Проверка релиза 1.3.0

Проверено 27 октября 2026 по московскому времени. Предыдущие проверки UI, миграций и восстановления: [1.2.1](1.2.1.md), [1.1](1.1.md). Этот документ фиксирует локальные проверки исходников; результаты подключения production фиксируются отдельно в журнале эксплуатации сервера.

- `uv run pytest -q`: **42 passed**, PostgreSQL 17. Новые тесты проверяют строгую границу MCP, все 114 схем, приватность validation errors, идемпотентность, изоляцию проектов, два Origin и неизменяемость пакетов.
- `uv run ruff check apps/api`: успешно.
- `npm run build` в apps/web: TypeScript и Vite успешно.
- `python3 scripts/package_skills.py` и `python3 scripts/check_skills.py`: семь пакетов 1.3.0, контракт 1.3.0, метаданные, ссылки, архивы и хеши.
- Схема БД не менялась: новая миграция не требуется. Пользователи, проекты, ревизии и результаты сохраняются.

Подтверждённый до исправления дефект: неизвестные аргументы MCP молча игнорировались. Воспроизведение новыми тестами дало 3 failed/1 passed; после исправления весь набор проходит. Проверка приватности ошибок проходила до исправления, утечка не заявляется.

В этой исторической проверке 14 модельных eval-сценариев подготовлены, но не исполнены. A/B, стоимость и токены не измерялись. Нагрузочное тестирование и формальный аудит безопасности/доступности в этом обновлении не проводились.
