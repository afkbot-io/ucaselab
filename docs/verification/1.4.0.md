# Проверка релиза 1.4.0

Проверено 27 октября 2026 года. Предыдущие проверки: [1.3.0](1.3.0.md), [1.2.1](1.2.1.md).

Добавлена одна публичная ссылка `/ai.md` для подключения агента: адрес MCP, выбор навыка и ссылки на Markdown/ZIP. `/api/agent/manifest` сообщает версии, размеры и SHA-256. В профиле есть копирование ссылки, переход к инструкции и настройкам доступа; отдельные навыки остаются доступны для ручной установки.

- `uv run pytest -q`: **45 passed** на PostgreSQL. Три новых теста проверяют всю цепочку публичная инструкция → каталог → семь Markdown/ZIP, хеши/содержимое, allowlist файлов, отсутствие пользовательского контекста и сохранение авторизации для MCP и проектного guide.
- `uv run ruff check apps/api`: успешно.
- TypeScript и Vite production build проходят.
- Семь пакетов 1.4.0 проверены `scripts/check_skills.py`. В MCP сохраняются 114 операций, `list_skills` дополнен bootstrap_url и manifest_url.
- Playwright: профиль на 1440×1000 и 390×844, фактическое содержимое буфера равно ссылке, переход к инструкции открывает отдельную вкладку. Переполнения по горизонтали нет. Локальные снимки — output/playwright/agent-link-*.png.

Ссылка содержит только общие материалы релиза. Токен и данные проекта туда не включаются; доступ к проектам требует отдельного Bearer-токена. Установка зависит от возможностей агентского клиента. Публичная ссылка сама по себе не подключает браузер/устройство и не выдаёт права.

Схема БД не менялась. При обновлении существующие проектные инструкции и данные не заменяются. Модельное A/B-сравнение и нагрузочное испытание в этом обновлении не проводились. Результаты удалённой проверки после выкладки фиксируются в журнале эксплуатации сервера.
