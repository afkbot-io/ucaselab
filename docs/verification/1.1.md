# Проверка релиза 1.1.0

Проверено 26 октября 2026 года на локальном Docker Compose с PostgreSQL 17 и Mailpit. Это результаты проверки приложения, а не запись о развёртывании на внешнем сервере.

## Изменения интерфейса 1.1

Спецификации выбираются поиском и тегами в основном блоке кейса перед вариантами данных. Теги кейсов, теги спецификаций и платформы имеют отдельные сохраняемые словари; дубли регистра/пробелов нормализуются. Переключение проектов — диалог с поиском; логотип ведёт к кейсам выбранного проекта. Название — UCaseLab, планы — «Кейс-планы».

Предложения разделены на новый сценарий и правку существующего. Новый кейс перед предложением не создаётся, описание достаточно; подготовленные шаги и источник кода необязательны. Выбор существующего кейса идёт через поиск. Для основных каталогов добавлены серверные фильтры, сортировки и пагинация, для общего поиска — пять видов сущностей и отдельные счётчики/продолжения.

В браузере проверены поисковый диалог проекта, выбор спецификации и тегов/платформ через Enter, оба варианта формы предложения, поиск существующего кейса, мобильная форма при 390 px. Скриншоты сохранены локально в output/playwright; они не входят в исходный релиз.

## Автоматические проверки

- `uv run ruff check apps/api` — успешно.
- `uv run pytest -q` — **28 passed** на PostgreSQL. Проверены регистрация, подтверждение почты, сброс доступа, CSRF, роли и изоляция проектов, черновики и публикации, конфликты версий, атомарное принятие предложений, закреплённые прогоны, неизменяемые результаты и отчёты, секреты, комментарии, пагинация, типы данных, MCP scopes и отзыв токена.
- `uv run python scripts/check_migrations.py` — новая изолированная схема, 38 таблиц приложения, расхождений миграции с моделями нет. Два параллельных создания кейсов дают разные номера; две передачи владения оставляют ровно одного руководителя. Временная схема удалена.
- `npm run build` — TypeScript и production-сборка Vite проходят.
- Полный контейнерный стек собран и запущен; readiness API отвечает успешно. API и PostgreSQL не публикуют порты в основной конфигурации; локальный web привязан к loopback.
- Официальный MCP SDK: initialize, 109 инструментов, чтение пользователя и проектов, чтение и изменение инструкции проекта. Временный токен отозван после проверки. Также автоматические тесты проверяют протокол 2026-07-28.
- Семь пакетов навыков версии 1.1.0: проверены структура, CRC ZIP, SHA-256 и совпадение исходных файлов.

## Реальный браузерный сценарий

В интерфейсе зарегистрирован пользователь, письмо получено в Mailpit, одноразовая ссылка подтвердила почту. Созданы проект, юзер-кейс регистрации с положительным и отрицательным вариантом, публикация, план и прогон.

Положительный вариант выполнен в отдельной вкладке: новая регистрация, доставка письма worker и подтверждение адреса. Для отрицательного варианта проверен некорректный email: браузер показывает ошибку формата и не отправляет запрос регистрации. В прогоне сохранены фактические наблюдения и скриншоты; обе проверки получили passed, поскольку наблюдения совпали с ожиданиями вариантов. Прогон закрыт, создан итоговый отчёт.

PDF/CSV/JSON скачаны через защищённый endpoint. PDF отрисован и визуально проверен: кириллица, таблица результатов, доказательства и контрольные суммы читаемы. Отчёт остаётся историческим снимком.

Интерфейс визуально проверен при ширине 1440 и 390 px. Проверено восстановление несохранённого локального черновика после перезагрузки, включая number, boolean и null. Проверочный несохранённый кейс удалён из локального хранилища без записи в БД.

## Резервная копия и восстановление

Выполнен `scripts/backup.sh`, затем `scripts/restore.sh` в **отдельном Compose-проекте**. После восстановления проверены вход, членство, расшифровка тестового аккаунта исходным ключом, неизменяемый отчёт и SHA-256 вложений. Основная БД не заменялась. Временные контейнеры и тома удалены.

## Границы проверки

Почта локально перехватывалась Mailpit. Доставку через SMTP пользователя, DNS и HTTPS необходимо проверить после настройки сервера по [DEPLOYMENT.md](../DEPLOYMENT.md). Workflow CI подготовлен; удалённый GitHub Actions запуск в этой среде не выполнялся. Нагрузочное испытание и формальный аудит доступности не проводились. Встроенные облачные браузеры/мобильные раннеры, OAuth discovery и публичные ссылки на отчёты относятся к следующим этапам, как указано в [реализованной модели](../IMPLEMENTATION.md).

Проверка MCP версии 1.1 выполнена официальным SDK на запущенном Compose: новые имена *_case_plan, фильтр поиска по содержимому, отдельные словари, составной поиск с entities и семь навыков. Через MCP отправлено предложение нового сценария поиска и тегов со ссылкой на фактическое изменение исходников. До принятия число юзер-кейсов не изменилось; временный credential отозван. Демонстрационный проект и текущая публикация регистрации получили имя UCaseLab; прежние прогоны и отчёты сохраняют свои исторические снимки.
