# Рабочее место проверки 1.2

Основная задача: понять, какой вариант выполняется, сравнить наблюдаемое с ожиданием, сохранить факт и перейти дальше. Три этапа: подготовка, выполнение, результаты. Очередь показывает юзер-кейс один раз и его варианты ниже. Прогресс измеряется сохранёнными результатами; успех, расхождение и невозможность выполнить различаются.

Палитра сохраняет UCaseLab: ink #18233b, white #ffffff, canvas #f4f6fa, blue #3659e3, line #e2e7f0; green #217a61 — совпало, red #be4655 — расхождение, amber #976411 — не удалось проверить. Manrope: заголовки 24/20 px, основной текст 14 px, пояснения 12–13 px.

На компьютере слева очередь и фильтры, справа один закреплённый вариант: данные → ожидаемый результат → шаги. Подготовка и назначение раскрываются по запросу. Итог фиксируется в отдельном диалоге с четырьмя понятными вариантами; успешный результат заранее не выбран. Нижняя строка показывает действие для текущего состояния. На мобильном очередь раскрывается кнопкой, содержимое читается одной колонкой.

API предоставляет обзор без снимков всех кейсов, постраничную очередь, один полный вариант, атомарный запуск/резервирование и сохранение итога с шагами. UI и MCP используют одну границу. Следующий вариант после сохранения выбирается для просмотра, его выполнение начинается явно. Обновление каждые пять секунд показывает работу коллег и агента, сохраняя локальный текст. Завершение прогона остаётся отдельным подтверждаемым действием; прогресс 100% не означает, что все ожидания совпали.
